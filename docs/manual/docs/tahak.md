# Rychlý přehled

Jedna strana k vytištění pro organistu. Podrobnosti v kapitolách [Ovladač](ovladac.md) a [Typické postupy](postupy.md).

## Spuštění písně

1. Zapněte ovladač: ON/OFF. Po 3 s `Hlavni menu`.
2. `Prehravac`, OK.
3. Číslice kódu. Písmeno A-D: nahoru (dolů jde zpět).
4. OK. `Spoustim`, pak `Prehravam`.

## Během hry

| Chcete | Stiskněte |
|---|---|
| zastavit | OK při vybraném `Stop` (jinak nejdřív doleva) |
| přidat sloku | doprava (`Opakovat`), OK; opakovaně |
| jinou píseň | zadejte kód, OK |
| opravit kód | doleva (nejdřív písmeno, pak číslice) |
| seznam písní | nahoru nebo dolů bez zadaných číslic |

Pozastavení ani pokračování neexistuje; zastavená píseň začne znovu od začátku.

## Vypnutí a baterie

- Vypnout: podržte ON/OFF 5 s (`Vypnuti`, `Drzte 5 s`).
- Samo se vypne po 20 min bez stisku (ne při USB kabelu).
- Displej usne po 30 s; první stisk jen probudí.
- Baterie: `Nastaveni`, `Baterie`. Před vybitím ovladač nic neukáže, kontrolujte ikonu. Nabíjení: USB-C kabel.

## Když se něco nedaří

| Na displeji | Co dělat |
|---|---|
| `Neznama 999` | zkontrolujte kód; `12` a `012` jsou různé; zkuste seznam písní |
| `Cekam na zakladnu` | zapněte základnu; ovladač zapněte znovu |
| `Cekam na PC` | zkontrolujte počítač a kabel USB mezi počítačem a základnou |
| `PC zaneprazdneno` | zkuste za chvíli |
| `Bez odpovedi`, `Zkuste znovu` | stiskněte OK znovu |
| `Slaba baterie` | nabijte |

Nic nepomohlo: dejte vědět správci a řekněte přesný text z displeje. Další příznaky viz [Řešení problémů](problemy.md).

Po výpadku proudu je napájení varhan vypnuto; zapne se samo při další písni.
